- (decision by user) Setter flow: open app -> create session -> select players involved -> log sets per player -> after logging, quick per-player summary window of the logs.
- (decision by user) Hitter flow mirrors setter's; on-court communication handles quick adjustments; reflection/review right after the game is the best time for hitter ratings.
- (decision) Hitter rating flow (resolves spec open question): one overall 0-3 rating per session per setter; available as soon as the setter creates the session with that hitter included; prompted by in-app 'To rate' card (+ push if platform allows).
- (assumption) Hitter rating stays open until the hitter's next session with that setter, then locks.
- (assumption) Logging screen: pick player tab, then set type + pass quality + rating; set type and pass stay selected from the previous entry; tapping rating commits the entry (1-3 taps per set). Undo on last entry.
- (assumption) Rating colours: 0 grey, 1 amber, 2 sky blue, 3 green; numerals always shown so colour is never the only cue. Brand red reserved for primary action and brand, not for ratings.
- (assumption) Pass quality chips use shape/label cues (Good / OK / Poor) with neutral fills; set types are navy-outlined chips.
- (assumption) Typography: system UI font stack, heavy weights for numerals and labels; tabular numerals in stats.
- (assumption) Logging tap targets >= 56px; all other targets >= 48px (sweaty hands).
- (assumption) Navigation: setter tabs Sessions / Progress / Coach / Team; hitter tabs Home / Setters / Team; settings via profile button.
- (assumption) Adding a player: '+' opens sheet (name, position); saves player to roster and produces an invite link the player uses to create their account.
- (assumption) A user can belong to more than one team; team switcher in header.
- (assumption) Logo is designed separately; DESIGN.md sets requirements only (navy/red/white, legible at home-screen size, works on light and dark).
- (assumption) English only; Australian audience.
