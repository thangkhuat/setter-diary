# Reporting Requirements

## v1

| View | Shows | Controls | Requirement |
| --- | --- | --- | --- |
| Consistency trend | Per calendar week: average rating; % hittable sets (rating 2 or 3) | Filter by set type | FR-7 |
| Hitter × set-type grid | Average rating per hitter/set-type cell, and change since a chosen date (e.g. back sets to a given hitter: 1.4 → 2.2 since August) | Pick comparison date | FR-8 |
| Personal dashboard | Viewer's own progress (v1: quality of sets they received), each team setter's trend, and the viewer's own row in each setter's grid | — | FR-9 |

Trend and grid are per setter. A hitter viewing a grid sees only their own row; the setter who owns it sees all rows.

## Deferred (out of scope for v1)

| View | Shows |
| --- | --- |
| Pass-quality breakdown | How set quality holds up off good, OK and poor passes |
