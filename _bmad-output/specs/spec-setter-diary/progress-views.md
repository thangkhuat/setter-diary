# Progress Views

| View | Shows | Controls | Cap |
| --- | --- | --- | --- |
| Consistency trend | Per calendar week: average rating; % hittable sets (rating 2 or 3) | Filter by set type | CAP-7 |
| Hitter × set-type grid | Average rating per hitter/set-type cell, and change since a chosen date (e.g. back sets to a given hitter: 1.4 → 2.2 since August) | Pick comparison date | CAP-8 |
| Personal dashboard | Viewer's own progress (v1: quality of sets they received) plus the setter's trend and grid | — | CAP-9 |
