# Access Matrix

| User | Can log | Can view |
| --- | --- | --- |
| Setter (primary user) | Every set, with full detail; roster; set-type list; sessions | Own progress across all hitters and set types |
| Hitter (teammate) | Optional rating on sets they received | Own progress (v1: quality of sets they received) plus the setter's progress |

Unresolved (see SPEC Open Questions): bench-teammate logging on the setter's behalf; whether the setter sees individual hitter ratings or only averages; whether teammates see other hitters' rows in the setter's grid.
